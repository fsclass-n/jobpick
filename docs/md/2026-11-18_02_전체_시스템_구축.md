# 2026-11-18 · 02. 전체 시스템 1차 구축

## 목적

요구사항 정의서에 따라 프런트엔드, 백엔드, RPA, AI, 배포 설정, 산출물을 한 번에 구축하고 로컬에서 검증합니다.

## 작업 내용

| 영역 | 내용 | 주요 파일 |
|---|---|---|
| 설정 | 단일 `.env`(프런트/백엔드/RPA 구분 표기), 단일 `requirements.txt`, `.venv` | `.env.example`, `requirements.txt` |
| 백엔드 | FastAPI 라우터 6종, 서비스 5종, 시드, 정식 관리자 생성 스크립트 | `backend/app/**`, `backend/scripts/create_admin.py` |
| 인증 | 권한별 JWT(별도 서명키·aud·만료), bcrypt, 잠금, TOTP, OAuth(Google/Naver/Kakao) | `security.py`, `deps.py`, `routers/oauth.py` |
| RPA | 수집기 4종, 정형화, upsert 파이프라인, CLI, OCR | `rpa/**` |
| AI | 규칙 기반 5영역 점수 + Gemini 병합, 폴백 | `services/analyzer.py` |
| 프런트 | 메인 매칭 인터랙션, 공통 레이아웃, 로그인 3종, 서비스 화면, 관리자 콘솔(정식/샌드박스), Mock API | `frontend/src/**` |
| 배포 | Render Blueprint, Netlify, GitHub Actions(영역별 배포 + Pages), Docker Compose | `render.yaml`, `netlify.toml`, `.github/workflows/deploy.yml`, `docker-compose.yml` |
| 문서 | 산출물 8종, 진행일지, 안내 페이지, PDF/PPTX 생성 스크립트 | `docs/**` |
