# 2026-11-18 · 01. 요구사항 정리 (dataquill → jobpick)

## 목적

dataquill(데이터 입력 자동화) 요구사항 문서를 기반으로, jobpick 주제에 맞는 프로젝트 요구사항을 확정합니다.

## 작업 내용

- **서비스 콘셉트**: RPA가 채용 공고를 수집하면, 생성형 AI가 사용자의 자소서와 대조해 합격 가능성을 분석하고 수정 가이드라인을 작성합니다.
- **팀**: 박미금(조장), 이오리, 김모란, 홍기흥
- **배포 도메인**

  | 구분 | 도메인 |
  |---|---|
  | 프런트엔드 데모 | jobpick.netlify.app |
  | 프런트엔드 | jobpick.onrender.com |
  | 백엔드 | jobpick-api.onrender.com |

- **추가 요구사항**
  - 독창적 비주얼·인터랙션
  - 전 페이지 공통 헤더·푸터
  - 권한별 로그인 3종: 일반 사용자 / 테스트 관리자 / 정식 관리자. 정식 관리자는 세션·권한 범위·접근 경로를 완전히 분리합니다.
- **핵심 서비스 페이지**: 공고 탐색, 자소서 관리(OCR, 버전), AI 분석 리포트, 분석 이력
- **관리자 기능**: 회원 관리, 모니터링, 수집 관리, 접속 로그
