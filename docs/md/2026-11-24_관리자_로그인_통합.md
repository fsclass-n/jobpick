# 2026-11-24 관리자 로그인 통합

## 변경 요약
- `/admin/login` 페이지와 `POST /api/admin/login` API 제거
- `POST /api/auth/login {email, password}` 신규 — 로그인 페이지에서 이메일·비밀번호로 모든 권한 진입
- 관리자 자격증명: `ADMIN_ACCESS_KEY`(단일 키) → `ADMIN_EMAIL` + `ADMIN_PASSWORD`(계정)로 교체
- 회원 관리 권한 선택지 `USER`/`TEST_ADMIN` → `USER`/`TEST_ADMIN`/`ADMIN` 3종으로 확장

## 동작 규칙 (스텁)
- `ADMIN_EMAIL`과 일치하는 이메일, 또는 회원 관리에서 `ADMIN`으로 지정된 계정 → `ADMIN_PASSWORD` 검증 후 `ADMIN` 토큰 발급 (5회 실패 시 15분 잠금 유지)
- 기존 회원 이메일 → 저장된 권한(`USER`/`TEST_ADMIN`) 토큰 발급, 신규 이메일은 `USER`로 자동 가입
- 환경 변수 관리자 이메일은 서버 기동 시 회원 목록에 `ADMIN`으로 표시되며, 잘못 강등돼도 다음 로그인 시 복구됨

## 수정 파일
- `backend/app/security.py`: `check_admin_key` → `check_admin_password`
- `backend/app/data.py`: `ADMIN_EMAIL` 회원 시드
- `backend/app/routers.py`: `/api/auth/login` 추가, `admin_auth` 라우터 제거, `RoleIn` 3종
- `backend/app/main.py`: `admin_auth` 제거
- `frontend/src/pages/Auth.jsx`: `AdminLogin` 제거, 이메일 로그인을 `/api/auth/login` 연결 (응답 권한별 이동)
- `frontend/src/App.jsx`: `admin/login` 라우트 제거, 가드 리다이렉트 `/login`으로
- `frontend/src/pages/Admin.jsx`: 권한 select에 `ADMIN` 추가, 안내 문구 변경
- `.env.example`, `AGENTS.md`, `readme.md`, `요구사항_명세서.md`: `ADMIN_*` 방식으로 갱신
