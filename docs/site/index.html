공고와 나를 맞대면,
합격이 보입니다

jobpick은 RPA가 수집한 채용 공고를 생성형 AI가 사용자의 자기소개서와 대조해 합격 가능성(적합도)을 분석하고, 문항별 수정 가이드라인을 작성해 주는 커리어 컨설팅 서비스입니다.

데모 체험하기 서비스 바로가기 GitHub 저장소 API 문서

네 단계로 끝나는 맞춤 컨설팅

공고를 찾고 자소서를 혼자 고치던 시간을 데이터 기반 피드백으로 바꿉니다.

1

공고 자동 수집

고용24 Open API, 채용 게시판(BS4/Playwright)에서 공고를 수집하고 자격요건·우대사항·인재상으로 정형화합니다. robots.txt를 준수합니다.

2

자소서 등록

텍스트 입력 또는 PDF·이미지 업로드(OCR)로 문항을 자동 분리하고, 수정할 때마다 버전을 남깁니다.

3

AI 대조 분석

Google Gemini와 규칙 기반 엔진이 키워드·요건·인재상·문장 완성도 5개 영역으로 적합도를 산출합니다.

4

수정 가이드

문항별 수정 가이드라인과 개선 예시 문장, 다음 행동을 제시하고 점수 변화를 추적합니다.

세 가지 계정 유형의 세션, 권한 범위, 접근 경로를 분리했습니다.
