## 5. 발견 및 조치 내역

| 문제 | 원인 | 조치 |
|---|---|---|
| `.test`/`.local` 도메인 테스트 계정 로그인 422 | `EmailStr` 가 특수 용도 도메인 거부 | 로그인 입력은 형식 정규식 검사로 변경 (가입은 EmailStr 유지) |
| 화면 전환 시 React "destroy is not a function" | 최신 Chromium 의 `window.scrollTo` 가 Promise 반환 → effect 반환값으로 처리됨 | effect 를 블록 문으로 변경 |
| 샌드박스 콘솔에서 SANDBOX 띠 중복 | 전역 헤더 띠 + 콘솔 범위 띠 | 콘솔 영역에서는 전역 띠 숨김 |
| 모바일 관리자 표가 화면 폭을 늘림 | 그리드 열 최소 폭이 표 너비를 따라감 | `grid-cols-1`, `minmax(0,1fr)` 적용 |
| 관리자 도넛 차트 범례 넘침 | 좁은 카드에서 가로 배치 | 세로 배치로 변경 |
